# QProtocol

Инструменты противостояния интернет-цензуре: **диагностика ограничений** и
разработка устойчивого транспорта (рабочее имя — «Пиросто»).

## Что здесь есть

| Компонент | Описание | Статус |
|---|---|---|
| `bin/qprotocol` (QPD) | Скомпилированный бинарь диагностики: занимает локальный порт, сам выполняет все пробы и показывает дашборд | ✅ |
| `app/src` | Исходники QPD (сборка: `./build.sh`, упаковка в один бинарь через Node SEA) | ✅ |
| `docs/ANALYSIS.md` | Разбор предыдущей попытки, как ТСПУ обнаруживает протоколы (2026), детектируемость «Пиросто», направление развития | ✅ |
| `docs/pirosto-spec.md` | Спецификация транспорта «Пиросто» | ⬜ план |

## Быстрый старт

```bash
./build.sh                                  # собрать бинарь bin/qprotocol
./bin/qprotocol serve --port 8787           # занять порт: дашборд + JSON API
./bin/qprotocol diag --out report.json      # разовая диагностика в JSON
./bin/qprotocol lab                         # лаборатория детектируемости «Пиросто»
```

Веб-интерфейс: `http://localhost:8787/` · API: `/api/report`, `/api/run`, `/api/lab`, `/api/health`.

## Что измеряет QPD

* DNS: системный резолвер, сырой UDP-DNS, DoH, отравление ответов;
* TCP/TLS: хендшейки, сертификаты, **JA3/JA4 «глазами DPI»**;
* SNI-фильтрация (блок-лист по домену vs виртуальный хостинг);
* Какой обход ClientHello работает в вашей сети: split, split-mid-sni, record-split, tiny-records;
* «Сигнал 3» ТСПУ: порог параллельных TLS-хендшейков (заморозки ~120 с);
* UDP/QUIC-пробы (пригодность для Hysteria2);
* Лаборатория «Пиросто»: энтропия, форма потока, тайминги → оценка риска детектирования.

## Направление (кратко)

Не изобретать криптографию с нуля: TLS 1.3 с ротируемым пулом отпечатков и
защитой от зондирования (REALITY-семантика) + минималистичный фрейминг с
паддингом и мультиплексированием (против ML-детекции формы потока) + гигиена
эндпоинтов (ASN/SNI/параллелизм) + fallback-цепочка транспортов. Подробности и
источники — в [docs/ANALYSIS.md](docs/ANALYSIS.md).

## Сборка

Требуется Node.js ≥ 20 (для SEA) и npm. `build.sh` склеивает `app/src/*.js`,
проверяет синтаксис, упаковывает в `bin/qprotocol` (один файл, без зависимостей).
